# 🛍 Product Card Component

A responsive product card built using **HTML5**, **CSS3**, and **JavaScript** following a mobile-first approach and clean CSS architecture principles.

This project started as an HTML and CSS practice project and was later enhanced with JavaScript, dynamic API data, loading states, and HTTP error handling.

---

## 📌 Features

- Mobile-first layout
- Responsive design
- Flexbox structure
- Clean global CSS reset
- Hover interactions
- Reusable component structure
- Max-width container control
- Dynamic product data
- Fake Store API integration
- Skeleton loading state
- CSS loading animation
- HTTP response validation
- Basic HTTP error handling

---

## 🎯 What I Practiced

### HTML & CSS

- Global CSS setup
- Box model control with `box-sizing`
- Flexbox layout structuring
- Managing `max-width` for better UI control
- Hover transitions
- Component-based thinking
- Skeleton loading UI
- CSS animations

### JavaScript

- Fetching data from an external API
- Using async/await
- Handling asynchronous operations with try/catch
- Validating HTTP responses with response.ok
- Basic HTTP status handling
- Destructuring API data
- Rendering dynamic content in the DOM
- Working with querySelectorAll()
- Using forEach() to manage UI states
- Toggling classes to switch between loading and loaded content

---

## 🔄 Application Flow

Page Load 
    ↓ 
Skeleton Loading State 
    ↓ 
Fetch Product Data 
    ↓ 
Validate HTTP Response 
    ↓ 
Render Product Data 
    ↓ 
Hide Skeleton 
    ↓ 
Display Product Content
