# 🛍 Product Card Component

A responsive product card built using **HTML5** and **CSS3**, following a mobile-first approach and clean CSS architecture principles.

This project is part of my frontend fundamentals practice while strengthening my JavaScript skills.

---

## 📌 Features

- Mobile-first layout
- Responsive design
- Flexbox structure
- Clean global CSS reset
- Hover interactions
- Reusable component structure
- Max-width container control

---

## 🛠 Technologies Used

- HTML5
- CSS3
- Flexbox
- Google Fonts
- Font Awesome Icons

---

## 📱 Responsive Behavior

- **Mobile:** Vertical layout (image on top, information below)
- **Tablet & Desktop:** Optimized spacing and layout adjustments

---

## 🎯 What I Practiced

- Global CSS setup
- Box model control with `box-sizing`
- Flexbox layout structuring
- Managing `max-width` for better UI control
- Hover transitions
- Component-based thinking

---

## 🚀 Future Improvements

- Add dynamic product data using JavaScript
- Implement interactive rating system
- Convert into reusable component for larger projects
- Connect to a backend product API (future full-stack version)
